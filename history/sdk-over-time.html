Sega's 32X development kits and SDK documents over time

Sega supported 32X developers with development hardware, tools and a stream of technical bulletins in 1994. This page lists what those documents were and when they appeared, which tells you which hardware fixes and rules existed at which point.

Summary#

  • April 1994 tools overview. Sega's overview lists Hitachi in-circuit emulators and an evaluation board for the SH-2DOC[S006-1]. It also lists an SH-2 compiler, cross assembler and debuggerDOC[S006-2].
  • Technical bulletins. Sega's Developer Technical Support issued 32X technical bulletins numbered 1 to 33 in 1994. Twenty-five are dated 1994-09-23, bulletins 23 and 28 are dated 1994-11-29, and bulletins 27 and 29 to 33 are dated 1994-12-08 (table below).
  • Hardware changes. The bulletins show the development hardware changing through 1994: target box 2.0, 2.0x, 2.1 and 3.0DOC[S144-1]DOC[S149-1][S152-1].
  • Mars Check Program. Sega's test program has 161 hardware tests and shipped in the 32X SDK. TascoDLX, a GenDev forum member, reported this in the thread "Mars Check Program results for Kega Fusion v3.61" (2009)COMM[S115-1]. See Test ROMs: Sega's Mars Check Program.
    • Commenting on issue #96 of the PicoDrive emulator's GitHub repository (2019), dilworks calls the program as old as the 32X itselfCOMM[S179-1].
  • Community kits came much later. Chilly Willy's devkit, for example, is published in the viciious/32XDK repository on GitHub as release 20220418CODE[S056-1] (see Devkits (Chilly Willy's devkit, marsdev)).

Where the bulletins' rules are explained#

Many bulletins carry hardware rules that still matter for code on a retail 32X. The pages below explain them:

  • RV bit (bulletins 6, 7, 9, 12): Bus arbitration and Cartridge bank switching.
  • Free-running timer initialization (10) and internal I/O access cycles (32): SH-2 on-chip peripherals on the 32X.
  • VDP shift bit (14): Screen shift (1-pixel horizontal scroll).
  • PWM registers and sound (19, 20): PWM sound (registers, cycle, FIFO).
  • TAS on the SH-2 (23): Dual-CPU synchronisation on the 32X.
  • SH-2 interrupt problems (27): Interrupts.
  • ID data and territory lockout (28), hardware recognition (29): Boot, security and ROM headers.
  • Target box versions (5, 15, 16, 21): Revisions and regions.

Pitfalls#

Bulletin numbers do not follow dates. Bulletins 23 and 28 are dated 1994-11-29, while 24 to 26 carry 1994-09-23 and 27 carries 1994-12-08 (see the table). Do not read a bulletin's number as its place in time.
